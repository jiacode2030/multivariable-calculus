# Multivariable Calculus Lab

An interactive multivariable calculus study site. The lessons follow the order of Princeton MAT 201 (Fall 2026). 33 lessons in 4 units, plus an optional review of the prerequisites (derivatives, integration, area between curves, conic sections, parametric curves, polar coordinates) and a Key formulas page; each one states the key idea, shows it in a 3D view and/or 2D map you can drag around, and ends with check-yourself questions.

- Open `index.html` in any browser. No install, no build step, no internet needed (except Google Fonts).
- Sections: Review (optional) · 1 Vectors & space · 2 Several variables · 3 Multiple integrals · 4 Vector calculus · Formula sheet.
- Navigation: course outline on the left ("All lessons" menu on phones) with topic search; Prev/Next buttons or the ← → keys. "Reset" restores a lesson's default settings.
- Link straight to a lesson with `#stokes`, `#polar`, etc.
- Hosted with GitHub Pages (Settings → Pages → Deploy from branch `main`, folder `/`).
